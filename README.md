# 指纹浏览器和 VPN 有什么区别？

「指纹浏览器」可以为不同项目保存网页状态和设备设置。VPN 主要改变网络连接路径，影响哪些应用还取决于系统和公司的路由策略。二者解决的是不同的日常问题。

## 用一个例子区分

如果员工必须先接入公司网络才能访问内部报表，按公司指引使用批准的 VPN 或其他接入方式。若同一员工需要同时查看两个测试角色的网页菜单，可以在两套环境里分别登录。仅连接公司网络，不会替你建第二套浏览环境。

## 同时使用时怎样验收？

先确认公司是否允许环境指定代理，再在目标窗口核对出口并打开内部测试页。另开系统浏览器复测，区分是整机连接异常，还是只有某个环境异常。记录网络模式即可，交接文档里不要保存线路密码。
